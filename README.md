## 👋 The person behind the code

I’m **Rajashekar**, a software engineer focused on resilient backends, cloud platforms, information retrieval, and useful AI applications. I enjoy connecting the pieces: the service behind the API, the data behind the recommendation, and the interface that makes it all understandable.

- ⚙️ **Engineering:** Distributed systems, event-driven services, and cloud-native architecture.
- 🧠 **Exploring:** Hybrid search, retrieval-augmented generation, and applied machine learning.
- 🎓 **Academic background:** Data Science at the University at Buffalo, SUNY.
- 📍 **Based in:** Buffalo, New York.

> **My favorite kind of project:** a difficult problem with a clear, useful experience on the other side.
